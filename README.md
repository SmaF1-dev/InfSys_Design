## О проекте

В качестве предметной области выбран **вариант №15 — «Отбор персонала (подбор кандидатов)»**.

Объект автоматизации — вымышленная IT-компания ООО «ВекторТех».

Цель проекта — разработать концепцию информационной системы для автоматизации процессов подбора персонала, управления вакансиями, кандидатами, собеседованиями и принятия решений о найме.

### Лабораторная работа №2

В рамках работы проведены анализ существующих бизнес-процессов (AS-IS), определение требований к системе, исследование готовых решений и сравнение трёх альтернативных концепций.

По результатам многокритериальной оценки выбрано внедрение готовой ATS-системы Talantix «Оптимальный».

Также подготовлены модели процессов TO-BE в нотации BPMN 2.0, технико-экономическое обоснование, реестр рисков, показатели качества и дорожная карта реализации.
